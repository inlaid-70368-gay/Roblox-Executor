## FAQ

### What is XCutors?

XCutors is a curated collection of five popular Roblox executors and a universal script loader, packaged together for easy access on Windows desktop.

### Which executors are included?

XCutors bundles Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal loader.

### Is this safe to download?

XCutors is scanned and built from verified sources. However, always download from official GitHub releases and scan files with your preferred anticomponent before use.

### Why does my anticomponent flag the download?

Some security software may flag executor tools due to their script injection nature. This is a common false positive. We recommend adding an exception for the installation folder.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. A 64-bit operating system is recommended.

### How do I update XCutors?

Open the XCutors dashboard and navigate to Settings > Check for Updates. Alternatively, visit the GitHub Releases page for the latest version.

### Can I request a new executor to be added?

Yes! Open an issue on the GitHub repository with the tag 'feature-request' and include the executor name and any relevant links.

### Does XCutors collect any data?

XCutors does not collect, store, or transmit any personal data. All script files and executor logs are stored locally on your machine.

### The executor is not loading — what should I do?

First, ensure Roblox is running and you are connected to a game. If the issue persists, check the XCutors logs in the Logs directory and consult the FAQ or open a support issue on GitHub.
